> **Автономный легковесный веб-просмотрщик медицинских DICOM-снимков (МРТ / КТ / Рентген) в одном HTML-файле.**
> Работает без бэкенда, без установки Node.js/серверов и без внешних библиотек (Zero-dependency). Открывается двойным кликом в любом браузере на ПК, смартфонах и планшетах.

---

## 🌟 Ключевые возможности (Features)

### 🩺 Медицинская визуализация (PACS Core)
- **Чистый JavaScript DICOM-парсер**: поддержка 16-бит/12-бит полутоновых изображений, распаковка заголовков и метаданных.
- **Высокопроизводительный 16-bit to 8-bit LUT**: 60+ FPS рендеринг через прямой `ArrayBuffer` / `Uint32Array` и Canvas.
- **Окно / Уровень (Window Width / Window Center - W/L)**:
  - Плавная регулировка контраста и яркости мышью или пальцем.
  - Предустановленные медицинские профили: *DICOM Default*, *Мягкие ткани*, *Костные структуры*, *Сухожилия и связки (T2)*, *Отек / STIR*, *Авто-контраст*.
- **Инверсия и цветовые карты**: Режим *Негатив*, палитры *Hot Iron*, *Rainbow*, *PET*.
- **Cine-анимация (Кинопетля)**: автовоспроизведение серии срезов с регулируемой скоростью (5–20 к/с) и режимами (по кругу / маятник).

### 📏 Измерительные инструменты (Measurements)
- **Калиброванная линейка**: физические расстояния в миллиметрах с учетом `PixelSpacing`.
- **Угломер (Cobb / 3-Point Angle)**: измерение анатомических углов в градусах.
- **Область интереса (ROI)**:
  - Автоматический расчет площади ($\text{мм}^2$).
  - Статистика сигнала: среднее значение ($\text{Mean}$), стандартное отклонение ($\text{SD}$), $\text{Min}$ и $\text{Max}$ интенсивность.
- **Пиксельный зонд в реальном времени**: $X, Y$, интенсивность сигнала ($SI$) и миллиметровые координаты.

### 📱 Полная поддержка мобильных устройств (Mobile & Touch)
- **Сенсорные жесты**:
  - 🤏 **Pinch-to-Zoom** (масштабирование двумя пальцами).
  - ✌️ **Панорамирование двумя пальцами** (перемещение снимка).
  - ☝️ **Управление инструментом одним пальцем** (W/L, линейка, перемещение).
  - 👆 **Одиночный тап** — скрыть/показать HUD-оверлей.
  - ⚡ **Двойной тап** — сброс зума по размеру экрана.
- **Выдвижные меню (Slide-out Drawers)**: боковые панели списка срезов и настроек на смартфонах не загромождают экран.

### 📂 Загрузка и экспорт
- **Открытие файлов и папок**: кнопки «📁 Файлы» и «📂 Папка» для пакетного чтения серий.
- **Drag & Drop**: перетаскивание файлов `.dcm` или целых директорий прямо в окно.
- **Экспорт**: сохранение текущего среза со всеми наложенными измерениями и HUD в формате PNG высокого качества.
- **Инспектор тегов DICOM**: полнотекстовый поиск по всем метаданным исследования с возможностью копирования.
- **Галерея срезов (Contact Sheet)**: плиточный предпросмотр всей серии одновременно.

## 🚀 Быстрый старт (Quick Start)

Никаких установок, зависимостей и сборщиков не требуется.

1. Скачайте файл `viewer.html`.
2. Откройте его в любом браузере:
   ```bash
   # Linux
   google-chrome viewer.html
   # или
   firefox viewer.html
   ```
3. Для просмотра своих снимков:
   - Нажмите **«📁 Файлы»** или **«📂 Папка»** в верхней панели.
   - Или просто перетащите файлы `.dcm` в окно браузера.

## 🏗 Архитектура и технологии

```
viewer.html
├── 📄 HTML5 Canvas & UI Layout
├── 🎨 Responsive CSS3 (Flexbox/Grid, Dark Medical Theme, Mobile Media Queries)
├── 📦 Embedded Pako (Минифицированный offline-декомпрессор GZIP)
├── 🔍 Pure JS DICOM Parser (Парсинг Explicit/Implicit Little Endian DICOM)
├── ⚡ 16-bit to 8-bit LUT Pipeline (Быстрое линейное преобразование и псевдоцвета)
└── 👆 Multi-touch & Mouse Event Controller (Pinch-to-zoom, Pan, Measurements)
```

- **Zero Network Overhead**: Работает полностью локально по протоколу `file:///`, данные пациента не покидают ваше устройство.
- **Medical Compliance**: Соответствует стандарту DICOM PS 3.3 для отображения матриц 512×512 и параметров сканирования.
